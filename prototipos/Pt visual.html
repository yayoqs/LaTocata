Vitrina visual

El sistema visual de LaTocata

Esta página reúne todos los elementos del diseño de LaTocata en un solo lugar. Arriba a la derecha se puede cambiar el tema visual y ver cómo responde el sistema completo. Cada componente aparece con ejemplos reales y contexto de uso.

Fundamento

Tres temas intercambiables

La app tiene tres temas visuales completos. Se cambian con un clic desde el shell y todos los componentes responden en cascada. Cada tema define su propia paleta, sus sombras y su carácter cromático sin que cambie la estructura de la interfaz.

Cómo se cambia el tema

En el shell de la app hay un botón de paleta arriba a la derecha. También se puede cambiar desde Ajustes. En esta vitrina el selector está arriba, en la barra pegajosa.

Carácter de cada tema

Cada tema está pensado para una situación distinta. Cálido para eventos de tarde en patios y casas. Nocturno para clubes, galpones y eventos con luz baja. Textil para eventos diurnos con identidad artesanal.

Cálido
Terracota, papel, cordel

Fondo crema. Acento marrón terroso. Sensación de cuaderno de campo, cordel, tinta.

Nocturno
Violeta, escenario, humo

Fondo oscuro. Acento violeta eléctrico. Sensación de club, foco puntual, madrugada.

Textil
Mostaza, rojo, verde profundo

Fondo beige cálido. Acento rojo quemado. Sensación de feria, manta, artesanía.

Fundamento

Paleta de colores

Cada tema define nueve colores base y cuatro semánticos. Los colores base son el lienzo general. Los semánticos señalan estados: éxito, aviso, error, información.

Colores de superficie

Definen el fondo y la jerarquía de capas: del fondo general al papel de las tarjetas.

Colores semánticos

Significan estados concretos y aparecen en píldoras, badges, alertas y elementos informativos.

Fundamento

Tipografía

Dos familias tipográficas. Fraunces para titulares y números con carácter, Figtree para cuerpo y controles. La combinación da personalidad sin perder legibilidad.

Fraunces — Titulares

Se usa para títulos, encabezados de sección, números grandes y cronómetros. Tiene peso variable y ofrece una sensación editorial.

Componente

Botones

Cuatro variantes con jerarquía clara. Primario para la acción principal, secundario para acciones alternativas, fantasma para acciones menores y peligro para lo destructivo.

Variantes

Cada variante tiene su propia lectura de peso visual. Se usan en el mismo contexto sin competir entre sí.

Tamaños

Tres tamaños. Chico para acciones dentro de listas, normal para el flujo estándar, grande para acciones de peso en pantallas vacías.

Estados

Deshabilitado mantiene la forma pero pierde opacidad.

Componente

Píldoras de estado

Muestran el estado de algo. Tienen color suave, texto corto y opcionalmente un punto. La variante viva hace latir el punto para indicar actividad en curso.

Variantes de color

Cada variante tiene un significado consistente en toda la app.

Píldora viva

La variante viva hace latir el punto en loop. Se usa solo para lo que está en curso ahora mismo: un acto en vivo, una votación abierta, una grabación activa.

Badges

A diferencia de las píldoras, los badges son etiquetas cortas y no señalan estado. Sirven para agrupar, categorizar o marcar. Son más pequeños y más discretos.

Toast

Aviso breve en la esquina inferior derecha. Dura tres segundos y se va solo. Se usa para confirmar acciones o avisar de un error.
